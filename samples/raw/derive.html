Knowledge point
In the Abelian anomaly theory with external U(1)L​×U(1)R​ fields, how to redistribute the gauge anomaly among different current definitions using an allowed local cubic counterterm, and uniquely fix its coefficient via the charge gauge symmetry that must be preserved.
Problem
Let M4​ be a closed four-manifold, with all gauge fields Abelian one-forms. The gauge variation of some one-loop effective action, in the background of external fields AL​, AR​, isδW=κ∫M4​​(λL​FL​∧FL​−λR​FR​∧FR​),FL,R​=dAL,R​.DefineAV​=2AL​+AR​​,AA​=2AL​−AR​​,and add the local termSloc​=c∫M4​​AA​∧AV​∧FV​,FV​=dAV​.Choose c so that, after adding Sloc​, the gauge anomaly remains only where physically allowed, while the preserved charge gauge symmetry is strictly anomaly-free. Write down the expression for c in terms of κ directly.
Final answer
显示答案
c=−4κ

Problem

某待测液可能含有 NO2^-、NO3^-、H2O2 中的一种或几种。取两份等体积试液：一份先用稀硫酸酸化，再加 KI-淀粉溶液，立即显蓝色；另一份直接加 KI-淀粉溶液，不显蓝。另取一份等体积试液，先加过量氨基磺酸，再用稀硫酸酸化，随后加入 KI-淀粉溶液，仍不显蓝。写出原待测液中必含的物种（用化学式表示）。

Final answer
显示答案

NO2^-

sample3-aromatic-claisen
Aromatic Claisen / crotyl aryl ether
Domain

Organic chemistry

Knowledge point

E-crotyl phenyl ether 热 [3,3]-σ 迁移中的 allyl-inversion 连通映射；不能直接按 Zaitsev 方向猜更高取代烯烃。

Problem

化合物 C/C=C/COc1ccccc1 于 200°C 加热，发生与 [3,3]-σ 迁移相关的热周环重排。请写出主产物的 SMILES；若生成外消旋体，写任一对映体即可，并用一句话说明为什么此处不能按 Zaitsev 方向作答。

Final answer
显示答案

可接受任一：C=C[C@H](C)c1ccccc1O 或 C=C[C@@H](C)c1ccccc1O。原因：更“稳定”的内烯候选对应错误的 allyl-inversion 连通。
