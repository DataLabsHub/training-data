## OpenSim Arm26 Computed Muscle Control Native Artifacts

### Software
OpenSim 4.5 on Windows 10/11 x64, using the OpenSim GUI workflow or `opensim-cmd`. OpenSim is free public biomechanics software; no license key or credentials are required.

### Objective
Starting only from the files in `input/`, reproduce the official OpenSim arm26 inverse-kinematics plus computed-muscle-control workflow and save the native setup XMLs and generated result files.

### Inputs
The input directory contains the arm26 model, marker trajectory, CMC task set, and reserve actuator set from the official OpenSim tutorial tree. Generate the requested result files locally from the bundled starter files.

### Required Workflow
1. Verify `input/checksums.sha256`.
2. Run inverse kinematics on `arm26.osim` using `arm26_elbow_flex.trc` over the full 0.0-1.0 s motion.
3. Run CMC on the same starter model, using the IK motion generated in step 2 as the desired kinematics and the bundled CMC task/actuator files.
4. Save the exact setup XML files used for the final IK and CMC runs under `output/setup/`.
5. Preserve the generated OpenSim result files under `output/ik/` and `output/cmc/`.
6. Write a concise `output/run_log.txt` identifying OpenSim 4.5, the command or GUI workflow used, and the two setup XML files executed.
7. Write `output/provenance.json` with `task_id`, `opensim_version`, `input_manifest_sha256`, a `setup_commands` list, and SHA-256 hashes for every required output file except `provenance.json`.

### Required Outputs
Create these paths exactly:
- `output/setup/arm26_Setup_InverseKinematics.xml`
- `output/setup/arm26_Setup_ComputedMuscleControl.xml`
- `output/ik/arm26_InverseKinematics.mot`
- `output/cmc/arm26_states.sto`
- `output/cmc/arm26_controls.sto`
- `output/cmc/arm26_Kinematics_q.sto`
- `output/cmc/arm26_pErr.sto`
- `output/run_log.txt`
- `output/provenance.json`

### Evaluation
The grader parses the submitted setup XMLs, verifies that they use the bundled starter files, checks the run log and provenance hashes, rejects copied precomputed outputs, and numerically compares the required `.mot`/`.sto` files against official OpenSim artifacts.

### Failure exit
If the VM software environment makes the task genuinely infeasible after a reasonable expert attempt, write `output/infeasible.md` with the specific blocker, software state, and attempted workflow. Do not submit fabricated or placeholder deliverables. This exit is only for genuine blockers; otherwise produce every required artifact exactly as specified.
