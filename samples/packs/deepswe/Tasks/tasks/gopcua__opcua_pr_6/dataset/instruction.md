# Add GetEndpoints service support

Extend the OPC UA binary service model so clients can encode, decode, and dispatch GetEndpoints messages and the structured values those messages contain. The library should expose a `LocalizedText` datatype with `NewLocalizedText(locale, text string)`, `DecodeLocalizedText([]byte)`, `Serialize`, `SerializeTo`, `Len`, `HasLocale`, `HasText`, `SetLocaleMask`, and `SetTextMask`; its encoding mask must use bit `0x01` for a present locale and bit `0x02` for present text, and absent strings should remain nil after decode. Replace the old string-table concept used for arrays of OPC UA strings with a public `StringArray` API: `NewStringArray([]string)` and `DecodeStringArray([]byte)` should round-trip normal arrays, encode a nil slice with an array size of `-1`, and encode an empty but non-nil slice with an array size of `0`.

Add public service structures for endpoint discovery data. `ApplicationDescription` should support URI strings, an application name as `LocalizedText`, an application type, gateway and discovery profile URIs, and discovery URIs as a `StringArray`, with constructor `NewApplicationDescription`. `UserTokenPolicy` and `UserTokenPolicyArray` should support policy id, token type, issued token type, issuer endpoint URI, and security policy URI, including token type constants for anonymous, username, certificate, and issued-token policies. `EndpointDescription` and `EndpointDescriptionArray` should support endpoint URL, server application description, server certificate, message security mode, security policy URI, user identity tokens, transport profile URI, and security level, with the existing public constructor spelling `NewEndpointDesctiption` and array constructor spelling `NewEndpointDesctiptionArray`.

Implement GetEndpoints request and response services with `GetEndpointRequest`, `NewGetEndpointRequest`, `DecodeGetEndpointRequest`, `GetEndpointResponse`, `NewGetEndpointResponse`, and `DecodeGetEndpointResponse`. A request must carry service type `ServiceTypeGetEndpointRequest` with numeric id `428`, a request header, endpoint URL, locale ids as `StringArray`, and profile URIs as `StringArray`. A response must carry service type `ServiceTypeGetEndpointResponse` with numeric id `431`, a response header, and endpoint descriptions as an `EndpointDescriptionArray`. The generic `Decode([]byte)` service dispatcher must recognize these two service type ids and return `*GetEndpointRequest` or `*GetEndpointResponse`, while preserving existing OpenSecureChannel request and response behavior.

The exact public Go API is part of this task. `LocalizedText` has exported fields `EncodingMask uint8`, `Locale *String`, and `Text *String`, an in-place `DecodeFromBytes` method, and the listed constructor, decoder, serialization, length, mask-query, and mask-setter methods. `StringArray` has exported fields `ArraySize int32` and `Strings []*String`, plus `DecodeFromBytes`, `Serialize`, `SerializeTo`, and `Len`; nil input has size `-1`, and a non-nil empty input has size `0`.

Use these exact exported discovery fields and signatures: `ApplicationDescription` has `ApplicationURI`, `ProductURI`, `ApplicationName`, `ApplicationType`, `GatewayServerURI`, `DiscoveryProfileURI`, and `DiscoveryURIs`, with types `*datatypes.String`, `*datatypes.String`, `*datatypes.LocalizedText`, `uint32`, `*datatypes.String`, `*datatypes.String`, and `*datatypes.StringArray`; `NewApplicationDescription(appURI, prodURI, appName string, appType uint32, gatewayURI, profileURI string, discoveryURIs []string) *ApplicationDescription` constructs it. `UserTokenPolicy` has `PolicyID *datatypes.String`, `TokenType uint32`, `IssuedTokenType *datatypes.String`, `IssuerEndpointURI *datatypes.String`, and `SecurityPolicyURI *datatypes.String`; `NewUserTokenPolicy(id string, tokenType uint32, issuedTokenType, issuerURI, securityPolicyURI string) *UserTokenPolicy` constructs it. `UserTokenPolicyArray` has `ArraySize int32` and `UserTokenPolicies []*UserTokenPolicy`, and `NewUserTokenPolicyArray` accepts `[]*UserTokenPolicy`.

`EndpointDescription` has `EndpointURL *datatypes.String`, `Server *ApplicationDescription`, `ServerCertificate *datatypes.ByteString`, `MessageSecurityMode uint32`, `SecurityPolicyURI *datatypes.String`, `UserIdentityTokens *UserTokenPolicyArray`, `TransportProfileURI *datatypes.String`, and `SecurityLevel uint8`. The existing misspelled constructors are `NewEndpointDesctiption(url string, server *ApplicationDescription, certificate []byte, messageSecurityMode uint32, securityPolicyURI string, userIdentityTokens *UserTokenPolicyArray, transportProfileURI string, securityLevel uint8) *EndpointDescription` and `NewEndpointDesctiptionArray([]*EndpointDescription) *EndpointDescriptionArray`; the array exposes `ArraySize int32` and `EndpointDescriptions []*EndpointDescription`. These discovery types and arrays provide their named decoders, `DecodeFromBytes`, `Serialize`, `SerializeTo`, and `Len`.

`GetEndpointRequest` embeds `*RequestHeader` and exposes `TypeID *datatypes.ExpandedNodeID`, `EndpointURL *datatypes.String`, `LocalIDs *datatypes.StringArray`, and `ProfileURIs *datatypes.StringArray`; its constructor is `NewGetEndpointRequest(timestamp time.Time, handle, diagnostics, timeout uint32, auditEntryID, endpointURL string, localIDs, profileURIs []string) *GetEndpointRequest`. `GetEndpointResponse` embeds `*ResponseHeader` and exposes `TypeID *datatypes.ExpandedNodeID` and `Endpoints *EndpointDescriptionArray`; its constructor is `NewGetEndpointResponse(timestamp time.Time, handle, result uint32, diagnostics *DiagnosticInfo, stringTable []string, endpoints ...*EndpointDescription) *GetEndpointResponse`. Both services provide their named decoder, `DecodeFromBytes`, `Serialize`, `SerializeTo`, `Len`, and `ServiceType` methods and implement `Service`. The public token constants are `UserTokenAnonymous`, `UserTokenUsername`, `UserTokenCertificate`, and `UserTokenIssuedToken`; application constants are `AppTypeServer`, `AppTypeClient`, `AppTypeClientAndServer`, and `AppTypeDiscoveryServer`.

Additional public contracts:
1. The datatype APIs are in package `github.com/wmnsk/gopcua/datatypes` (package name `datatypes`), and the discovery and GetEndpoints APIs are in package `github.com/wmnsk/gopcua/services` (package name `services`).
2. Export these named service decoders from package `github.com/wmnsk/gopcua/services` with the exact signatures `DecodeApplicationDescription([]byte) (*ApplicationDescription, error)`, `DecodeEndpointDescription([]byte) (*EndpointDescription, error)`, `DecodeEndpointDescriptionArray([]byte) (*EndpointDescriptionArray, error)`, `DecodeUserTokenPolicy([]byte) (*UserTokenPolicy, error)`, and `DecodeUserTokenPolicyArray([]byte) (*UserTokenPolicyArray, error)`.
3. `NewApplicationDescription(appURI, prodURI, appName, appType, gatewayURI, profileURI, discoveryURIs)` initializes `DiscoveryProfileURI` from `prodURI` (the second string argument), so the serialized `DiscoveryProfileURI` value is the product URI; this is the required observable constructor and wire behavior.
4. The application constants have values `AppTypeServer=0`, `AppTypeClient=1`, `AppTypeClientAndServer=2`, and `AppTypeDiscoveryServer=3`; the user-token constants have values `UserTokenAnonymous=0`, `UserTokenUsername=1`, `UserTokenCertificate=2`, and `UserTokenIssuedToken=3`.
5. `LocalizedText` is encoded as `EncodingMask`, followed by `Locale` when bit `0x01` is set and then `Text` when bit `0x02` is set; `StringArray` is encoded as its signed little-endian `ArraySize` followed by each `Strings` element in order.
6. `ApplicationDescription` serializes its fields in this order: `ApplicationURI`, `ProductURI`, `ApplicationName`, `ApplicationType`, `GatewayServerURI`, `DiscoveryProfileURI`, `DiscoveryURIs`. `UserTokenPolicy` serializes `PolicyID`, `TokenType`, `IssuedTokenType`, `IssuerEndpointURI`, and `SecurityPolicyURI` in that order.
7. `EndpointDescription` serializes `EndpointURL`, `Server`, `ServerCertificate`, `MessageSecurityMode`, `SecurityPolicyURI`, `UserIdentityTokens`, `TransportProfileURI`, and `SecurityLevel` in that order; arrays write their signed little-endian `ArraySize` followed by elements in slice order.
8. `GetEndpointRequest` serializes `TypeID`, `RequestHeader`, `EndpointURL`, `LocalIDs`, and `ProfileURIs` in that order. `GetEndpointResponse` serializes `TypeID`, `ResponseHeader` (including the constructor's `stringTable` as its string table), and `Endpoints` in that order.
9. The existing service constants used by this API remain `ReqTypeIssue=0`, `SecModeNone=1`, `ServiceTypeOpenSecureChannelRequest=446`, and `ServiceTypeOpenSecureChannelResponse=449`.
10. The exact method signatures are `DecodeLocalizedText([]byte) (*LocalizedText, error)`, `(*LocalizedText).DecodeFromBytes([]byte) error`, `(*LocalizedText).Serialize() ([]byte, error)`, `(*LocalizedText).SerializeTo([]byte) error`, `(*LocalizedText).Len() int`, `(*LocalizedText).HasLocale() bool`, `(*LocalizedText).HasText() bool`, `(*LocalizedText).SetLocaleMask()`, `(*LocalizedText).SetTextMask()`, `DecodeStringArray([]byte) (*StringArray, error)`, `(*StringArray).DecodeFromBytes([]byte) error`, `(*StringArray).Serialize() ([]byte, error)`, `(*StringArray).SerializeTo([]byte) error`, and `(*StringArray).Len() int`.
11. A null OPC UA `ByteString` (encoded length `-1`) has no value bytes, and `ServerCertificate.Get()` is nil after decoding it; an empty certificate passed to `NewEndpointDesctiption` uses that null encoding.
12. Each discovery type and array, `GetEndpointRequest`, and `GetEndpointResponse` provides `DecodeFromBytes([]byte) error`, `Serialize() ([]byte, error)`, `SerializeTo([]byte) error`, and `Len() int`; both GetEndpoints services also provide `ServiceType() uint16` and implement `Service`. `NewUserTokenPolicyArray([]*UserTokenPolicy)` returns `*UserTokenPolicyArray`.
13. `NewLocalizedText` treats an empty `locale` as an absent locale and an empty `text` as absent text, leaving the corresponding mask bits clear and pointers nil.
14. The endpoint discovery constructors use `AppTypeServer=0`, `UserTokenAnonymous=0`, and `SecModeNone=1` for their server and security-mode values.
15. The GetEndpoints service constants are `ServiceTypeGetEndpointRequest=428` and `ServiceTypeGetEndpointResponse=431`; its endpoint examples use `AppTypeServer=0`, `UserTokenAnonymous=0`, and `SecModeNone=1`.
