# 修复农场围栏柱悬空

初态由 `assets/create_base.py` 生成，`runner/run.sh` 在执行建模代码前加载。这是一个程序生成的农场简化场景，
用于验证环境管线，并非原始长程轨迹中的工程快照。

请将 `FencePost_01` 至 `FencePost_04` 的底面移动到地面顶面 z=0。
每根柱子的最低点与 z=0 的距离不得超过 0.002 米。
只允许沿世界坐标 Z 轴平移这四个对象；不得改变它们的几何、X/Y 位置、
旋转、缩放、材质或可见性。其他对象、相机、灯光、世界和场景设置保持不变。
保留全部对象，禁止增加对象、约束、动画、修改器、外链资源或脚本。

使用 Blender Python API（bpy）或命令行编辑工程，保存最终文件到
`/task/output/result.blend`。评估器会在独立进程中重新读取工程并测量几何。
只提交截图、JSON 报告或修改对象名称不会通过。此任务不评估农场视觉还原程度。

可用命令示例：
```bash
bash runner/run.sh --script starter/main.py
```
每个 episode 从新的输入工程开始。完成后结束任务，由评估器提供终局奖励。
