# 根据参考图重建农场

根据 `/task/references/reference.png` 创建可编辑的 Blender 农场工程。
要求建筑、地形、道路、水域、围栏、植被和农场设施的布局，以及材质、
相机视角和光照尽可能匹配参考图。保留实际三维几何与可编辑材质；
不能把参考图贴在平面上充当场景。保存 `/task/output/result.blend`。

运行时为 Blender 5.2.2（无界面 bpy）。本任务使用 4 CPU / 16 GiB 的评测预算。
依赖应打包进工程，或保存于提交目录内并采用相对路径；禁止外部绝对路径和符号链接。
评测端独立重开工程、渲染多视图并按固定 31 项 rubric 评分。
确认用参考图贴板替代主要三维场景、核心工程缺失或不可编辑时奖励为 0。
合法但质量不足的工程按原连续奖励公式评分；证据不足时暂不产生训练奖励。
